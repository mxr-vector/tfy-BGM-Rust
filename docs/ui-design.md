# 听风吟 · GPUI 界面设计规范

听风吟面向从本地曲库挑选、试听、导出配乐和编排节目的用户。浏览时先认场景封套，再比较曲名、分类和时长。专注试听时，当前曲目占据整个内容区，底栏保持在原位。

## 窗口与导航

| 区域 | 基准 | 内容与行为 |
| --- | --- | --- |
| 左侧栏 | 204 pt | 上方留出系统窗口按钮空间。品牌下方依次为音乐库、我的收藏、节目单。目录操作和曲库来源靠下。 |
| 顶部工具栏 | 66 pt | 搜索靠近内容起点，导入、导出设置、壁纸与设置靠右。排序和多选放在曲目表上方。 |
| 内容 | 左右各 24 pt | 页面标题和主要操作同排。分类封套、表格和节目时间轴对齐同一条左边线。 |
| 播放栏 | 84 pt | 左侧封套和曲名打开歌曲页，中间控制播放和进度，右侧管理音量、队列和收藏。 |
| 歌曲页 | 内容区全宽 | 左侧黑胶唱片，右侧曲名和本地标签。左上收起，底栏继续控制同一队列。 |

默认窗口为 1240 × 820 pt，最小窗口为 1020 × 680 pt。高度低于 750 pt 时，封套缩为 78 pt 高，为曲目列表预留空间。宽度低于 1130 pt 时，曲目信息、音量滑轨和歌曲页标题相应收紧。

## 色彩和字体

| 角色 | 颜色 | 使用位置 |
| --- | --- | --- |
| 品牌红 | `#D92E4B` | 活跃导航、主播放按钮、当前曲名、进度与收藏，悬停加深至 `#C32341` |
| 浅红 | `#FFE9ED` | 队列当前项和局部选中背景 |
| 页面 / 侧栏 / 面板 | `#FAFAFB` / `#F1F3F5` / `#FFFFFF` | 浏览区、导航区和阅读面 |
| 主文字 / 次文字 / 辅助文字 | `#222735` / `#515B6D` / `#657083` | 标题与曲名、标签、时间和路径 |
| 分隔线 / 删除操作 | `#E2E4E9` / `#AA283B` | 分栏、表格、弹窗和危险操作 |

默认中文字体为苹方，沿用用户的界面字体偏好。页面标题 29 pt 加粗，歌曲标题 32–40 pt 加粗，分区标题 15 pt 半粗，曲名与操作 12–14 pt，计数与辅助资料 10–12 pt。标签与数据分列，长曲名优先获得弹性宽度。

## 封套和曲目

六种内置场景使用同一组无字风景插画。欢快用橙色海岸，独处用月夜湖面，回忆用紫色电线杆，史诗用红色山峰，古风用青绿山水，乡村用金色田野。分类 ID 决定美术，名称和数量始终读取曲库。自定义分类沿用自身色彩和图标。

封套栏一屏六列，列间距 12 pt。封套下显示名称与曲数，选中的图上加勾。更多分类支持横向滚动和翻组按钮。搜索与收藏优先展示结果。曲目表使用 52 pt 行高，依次展示序号、32 pt 封套与曲名、分类、时长、收藏和更多操作。当前项同时显示底色和曲名强调，播放中另有播放标记。

## 歌曲页与状态

- 点击底栏左侧封套、曲名或展开箭头进入歌曲页。再次点击、按 ⌘↵、按 Esc 或点「收起播放页」返回。Esc 优先关闭上层诊断、队列或编辑框。
- 唱片中心和远景取自当前分类。深色遮罩为白色文字保留对比。艺人和专辑取自文件标签，缺失的字段直接收起，时长优先使用解码结果。
- 音频诊断和 A/B 循环位于曲目资料下方。队列、音量、进度和播放命令由底栏共享。切歌后封套与资料跟随当前曲目。
- 队列为空时，底栏提示从曲库选歌。退出播放页后恢复原来的筛选、滚动位置或节目编辑草稿。
- 浏览页的自定义壁纸沿用原有透明度、模糊和填充偏好。歌曲页使用当前曲目所属场景的背景。

## 动效与长文本

歌曲页从底栏方向移动并淡入，收起时反向过渡。标准行程为 52 pt，全程 260 ms。连续触发时从当前画面反向。底栏固定，播放照常进行。macOS 启用「减少动态效果」时，歌曲页直接切换。

文件名、曲名、分类和设备名等外部文本应按容器可用宽度布局。单行缩略使用 `min_w(px(0.)).truncate()`，同一行的图标、状态和操作保留空间。需要识别完整名称时，在悬停提示或详情中提供全文。

## 底栏、搜索和设置

- 播放或暂停由中央按钮的图标表达。底栏右侧依次轮换顺序播放、单曲循环和随机播放，切换时显示约一秒的文字反馈。
- 搜索图标、22 pt 输入行和快捷键提示共用垂直中心。输入内容长于容器时，横向偏移跟随光标和输入法位置。
- 工具栏的设置按钮和 ⌘, 都能打开设置。Esc 先关闭字体选择器，再关闭设置。
- 工作区、设置、弹层和壁纸遮罩共用浅色或深色语义色。默认跟随 macOS，常规页可固定浅色或深色。

| 页面 | 控件 | 可见状态和操作 |
| --- | --- | --- |
| 常规 | 外观、界面字体 | 外观三选一。字体按钮显示当前名称，列表可搜索已安装字体并有选中标记。 |
| 常规 | 登录启动、菜单栏图标、关闭窗口 | 两个独立开关。关闭行为可直接选询问、退出或隐藏，选择隐藏会开启菜单栏入口。 |
| 常规 | 配置文件 | 按钮在 Finder 显示配置文件。 |
| 播放 | 自动播放、屏幕唤醒、交叉淡入淡出 | 开关显示当前状态。淡入淡出用滑杆，零秒显示关闭。 |
| 播放 | 已配置输出、可添加设备 | 两组提供数量和名称。已配置设备可单独调节音量、静音、停用，可移除额外设备。离线设备保留配置并标明状态。 |
| 模型 | 模型目录、下载地址、ASR 识别 | 默认模型提供完整性检查、补齐和重新下载。推理库可用性单独显示。下载中可取消，模型加载后可选择单声道 WAV。 |
| 第三方接入 | 本机接口、令牌、跨域 | 显示运行或待重启状态，可复制地址。保存、清除令牌是独立操作，指定来源可单独保存。 |

## 扩展与验收

新页面从 `src/design.rs` 取语义色与尺寸。视图中的 `hero_button`、`tool_button` 和 `icon_button` 分别承担主要操作、具名工具和图标操作。单独的图标入口提供悬停名称。封套从 `src/assets.rs` 和 `assets/sleeves/` 注册，列表、底栏和唱片中心共用 `sleeve`。

验收从默认窗口与 1020 × 680 最小窗口各走一次。用复制的曲库和独立配置，可重复执行下表。新功能的验收场景写入对应 OpenSpec。

| 区域 | 操作与数据 | 验收标准 |
| --- | --- | --- |
| 曲库、收藏和选歌器 | 空列表、长中文、无空格英文、缺失标签、七个以上分类、多选 | 列表可滚动，曲名不遮挡时长、选中标记或行操作 |
| 底栏和歌曲页 | 暂停、播放、切歌、清空队列，用封面、⌘↵、Esc 展开或收起 | 切换方向正确，底栏固定，播放和原页筛选连续 |
| 动画边界 | 展开中立即收起、收起中立即展开、开启系统减少动态效果 | 从当前位置反向，最终页面与输入一致，系统偏好生效 |
| 壁纸和导出弹层 | 用超长文件名、切换默认与自定义壁纸、改变填充 | 选中标记完整，悬停可读全名，最下方设置可操作 |
| 节目单、弹窗与设置 | 长节目名、开启草稿后往返歌曲页、切换字体与外观、进出诊断或队列 | 草稿得以保留，按钮可达，Esc 优先关闭顶层 |
| 设置与播放栏 | 循环切换模式、拖动淡入淡出或设备音量滑杆、添加与移除设备、打开第三方接入 | 提示按时消失，设备名称和计数一致，跨页操作状态清晰 |
