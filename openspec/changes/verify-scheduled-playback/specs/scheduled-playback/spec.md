## ADDED Requirements

### Requirement: 时段校验与接管

节目单 MUST 遵循本地时间、左闭右开、互不重叠和文档的数量与字符串格式限制。

#### Scenario: 相邻与重叠

- **WHEN** 保存两个相邻时段，再尝试创建重叠时段
- **THEN** 相邻时段可保存，重叠时显示冲突节目名并拒绝

#### Scenario: 接管与手动冲突

- **WHEN** 某节目生效后用户尝试界面和 API 手动点播
- **THEN** 播放由节目单控制并显示提醒，API 返回冲突状态

### Requirement: 恢复调度

调度 SHALL 每秒检查，覆盖两分钟回看、休眠恢复和保存后即时对齐。

#### Scenario: 最小化和休眠

- **WHEN** 窗口最小化或系统休眠超过 3 分钟后返回
- **THEN** 切到当前节目中最晚一首已到点的曲目，未到点的歌曲不会提前进入自然播放
