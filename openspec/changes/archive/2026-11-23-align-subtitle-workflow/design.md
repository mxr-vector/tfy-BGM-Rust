## Context

契约来自作者文档 §2 的 F17 与 §4.7，文档基线为 `e59ee18`。F17 生成与记录契约已核对 `bgm-tauri2@8ba4f85`，曲库核心仍使用 `63a0598`。

## Decisions

曲目菜单、播放页和字幕页搜索选择器都将曲目加入「字幕生成」页并选中，按稳定键去重。用户在字幕页选择人声分离模型、确认固定伴奏模型及输出角色后，点击「开始分离并识别」才启动任务。字幕页显示模型状态、任务进度及结果。待生成曲目仅在当前会话保留。生成使用已加载的 ASR，先运行双轨分离，校验两条 WAV，再把人声经 FFmpeg 转为 16 kHz 单声道 PCM。识别进度按 ASR 分段报告。音轨与字幕先暂存，落盘时按稳定键验证源文件及现有字幕版本。分离目录交换后提交字幕 JSON，JSON 提交失败时恢复原分离目录。生成成功后刷新列表和当前曲目的播放预览。

歌曲页为已有字幕显示 SRT/LRC 格式选择、编辑和导出。macOS 使用系统多行文本表单，保存失败时携带原输入及错误重新显示。格式偏好写入 `subtitleFormat`。保存保留 `createdAtMs` 和既有元数据，更新 `updatedAtMs`，并让当前歌曲预览重新加载。

以曲目稳定键串行化 GPUI 写入，保存前复查所编辑的记录。JSON 和该曲目分离目录内由记录引用的 SRT/LRC 先分别暂存，再替换，最后提交 JSON。替换失败时恢复本次已经替换的派生文件。导入记录中的外部文件引用保持原值。

曲目改名、移分类和文件监听识别出的同名移动复用稳定键迁移。迁移保留创建时间、编辑时间和额外字段，更新分离清单和本地引用。新路径使用 FNV-1a 64 与安全化稳定键的 48 字符前缀，读取按哈希后缀核对记录内的键；哈希和前缀算法与主线一致。目标冲突时保留原记录，提交 JSON 失败时恢复分离目录和清单。

字幕页按生成时间显示记录，可预览和导出。曲目软删除或外部移除后仍可使用字幕。明确删除字幕时，先暂存记录及归属可验证的本地分离目录，再清理暂存内容。

分段编辑保留每段的开始与结束秒数。新增、修改和删除作用于草稿，保存沿用原文编辑的校验、冲突检测及文件回滚。字幕页的音频入口从本应用的分离目录定位人声和伴奏，并交给 macOS 默认播放器。缺失、不完整或归属无法确认时显示原因。

## Verification
