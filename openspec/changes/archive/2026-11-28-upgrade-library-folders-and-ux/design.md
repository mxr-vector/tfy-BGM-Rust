## 多文件夹持久化与升级迁移

- 在配置目录新增 `library-folders.json`（version = 1），保存有序的 `folders: Vec<LibraryFolderEntry>`（`id`、`path`、`legacyKey`）。保持 `prefs.json` v5 字段数量与既有共享核心契约不变。
- 若存在 `TFY_BGM_DIR` 环境变量且指向有效目录，则作为临时单源运行且不覆写 `library-folders.json`。
- 首次从旧版本升级（`library-folders.json` 不存在）时：
  - 若 `prefs.library_dir` 非空，迁移为唯一条目 `{ id, path, legacyKey: true }`（即使该目录当前离线也完整保留，不回退丢配置）。
  - 否则解析默认曲库根目录迁入为 `{ id, path, legacyKey: true }`。
- 旧条目（`legacyKey = true`）保持既有 `{category}/{stem}` 稳定键，确保既有收藏、节目单、循环点、字幕与分离产物无损衔接。用户新添加的文件夹（`legacyKey = false`）使用 `@{folder_id}/{category}/{stem}`（或未分类曲目 `@{folder_id}/_/{rel_stem}`）作为稳定键，跨目录同名文件互不覆盖且不串曲。

## 扫描、父子目录去重与离线容错

- 全局维护 `seen_canonical_files: HashSet<PathBuf>`，同一磁盘物理文件不会被收录两次。
- 扫描非 legacy 目录时，既扫描已注册分类子目录（单层，同主干按 `AUDIO_EXTENSIONS` 格式优先级去重），也递归扫描非隐藏、非已注册分类子目录下的音频归入「未分类」（`_uncategorized`），并跳过本身已被配置为独立音乐文件夹的路径及符号链接。
- 添加多个文件夹时按路径深度排序并过滤重复或已被祖先覆盖的子目录；若先添加子目录后添加父目录，保留子目录现有键与关联元数据，父目录扫描自动跳过该子目录，避免重复收录和收藏丢失。
- 任意文件夹离线时，保留其在 `library-folders.json` 中的配置和原有关联数据（不因离线清理收藏/循环点）；若全部目录均离线，保留最近一次扫描到的曲目列表并显示恢复条；重连后监听与补偿扫描自动恢复。

## 导入目标与界面层级

- 选择导入音频文件后统一弹出导入确认弹窗：展示目标文件夹选择（单目录直显路径，多目录支持点选）和目标分类单选，并实时预览写入目录路径（如 `剪辑配乐/epic/`），点击「开始导入」才写入磁盘。
- 侧栏左下角收敛为单一「音乐文件夹」入口，释放侧栏垂直空间使 7 个主导航项在最小窗口下完整可见。管理界面聚焦「添加文件夹…」，每行次级菜单提供「在访达中打开」与「从音乐库移除」（确认提示明确说明仅停止收录、保留磁盘文件），底部提供低层级「重新扫描」入口。
- 顶栏仅保留搜索框、导入音乐和设置；壁纸与导出设置收敛至设置弹窗的独立分页。首页标题区汇总曲目与文件夹数量，常规提示改为底部悬浮自动消失 Toast。
- 新增 `src/view/controls.rs` 统一按钮语意、分段控制器、纯开关、复选框、选项胶囊、输入框焦距高亮与弹窗关闭交互；分离 `keyboard_focus_visible` 状态，仅在 Tab/Shift-Tab 键盘导航时显示焦点框；`TextField` 显式撑满容器宽度避免工具与设置表单输入框塌缩。

## 内嵌通用推理库托管与引导

- 在 `src/library/sherpa.rs` 增加应用托管目录 `config_dir()/runtime/sherpa-onnx-2.0.2`，按 `TFY_ASR_LIBRARY` → 应用包内随附 `Contents/Resources/asr/` → 程序同级 `asr/` → 托管目录顺序查找通用动态库，不写入只读 `.app` 包内部并天然受 `TFY_BGM_CONFIG_DIR` 隔离。
- 内嵌 `RuntimeDownload` 按当前 `OS/Arch` 自动定位官方 `v2.0.2` 共享库压缩包，经临时目录 `/usr/bin/curl` 下载、SHA-256 摘要校验（macOS 包内置实测哈希）、`/usr/bin/tar` 提取动态库并调用 `open()` 验证版本导出字符串 `2.0.2` 后原子替换发布；同时保留「导入本地包…」入口供离线安装 `.tar.bz2` 归档、目录或单库文件。
- 设置中心「语音模型」页及「文生语音」「字幕生成」「人声分离」入口在缺少推理库时直接提供「一键安装推理库」和跳转「语音模型设置」的操作入口，展示内嵌进度与取消按钮，不再要求用户跳转 GitHub 自行挑选压缩包。
- 「设置 → 语音模型」重构为四张统一结构的状态卡片（`通用推理引擎`、`语音识别模型`、`模型目录` 与默认折叠的 `高级选项`），合并同一模型的重复展示与长路径换行，在 780 × 560 弹窗内一屏完成关键配置，并在字幕页与缺失弹窗支持对已下载完整模型直接一键启用。
