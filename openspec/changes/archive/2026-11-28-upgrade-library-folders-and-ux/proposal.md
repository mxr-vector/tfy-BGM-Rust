## Why

用户经常将本地配乐分散存放在多个文件夹（例如本地「剪辑配乐」与外置硬盘「项目素材」），希望它们在同一个音乐库中共同浏览、搜索与播放，并在左下角用更直观的「音乐文件夹」管理方式替代「重新扫描 / 切换 / 恢复默认」的心智负担。同时，目前首页顶部四个同权重按钮挤占视野、信息计数重复、提示文案常驻占位，且设置中心、桌面控件、对话框、播放栏、节目单和制作工具页存在多处交互不一致、焦点残留红框、元素 ID 冲突及排版拥挤问题，需要一次系统性的 UI 与人机交互升级。

## What Changes

- 支持多文件夹聚合收录（`library-folders.json`），兼容旧版单目录配置自动迁移并保留原曲库、收藏、节目单与循环点；支持系统多选添加、跨目录同名隔离不串曲、父子目录去重、外置目录离线容错与重连恢复。
- 将侧栏左下角收敛为单一「音乐文件夹」入口，点击打开文件夹管理界面（「添加文件夹…」、每行名称与区分路径、次级菜单「在访达中打开」与「从音乐库移除」且确认文案明确保留磁盘文件、空状态直达添加、低层级手动刷新入口）。
- 明确导入音频的目标文件夹与目标分类选择并展示写入路径预览。
- 重构首页信息层级：顶栏收敛为搜索、导入音乐与设置，将壁纸与导出设置整合进新版双栏设置中心；消除重复计数与常驻扫描占位改为自动消失 Toast；改进场景封套与曲目表对齐、右键菜单及多选态。
- 全面升级应用各处交互与控件一致性（全局键盘焦点环与鼠标点击分离、统一按钮/分段控制器/开关/复选框/输入框/弹窗遮罩关闭、修复所有循环静态元素 ID 冲突、优化设置/节目单/字幕/音频工具/歌单迁移/文生语音/桌面歌词布局）。
- 内嵌 `sherpa-onnx 2.0.2` 通用推理库自动下载与安装器（按当前系统/架构匹配官方共享库归档并做 SHA-256 与版本接口校验），并在文生语音、字幕生成、人声分离及设置页面提供直达一键安装与跳转到模型设置的清晰引导；同步修复输入框嵌套在 `input_box` 中的宽度塌缩导致文字不可见的问题。

## Impact

- 涉及 `src/library.rs`、`src/watch.rs`、`src/audio_index.rs`、`src/icons.rs`、`src/actions.rs`、`src/main.rs`、`src/text_input.rs`、`src/desktop_lyrics.rs`、`src/view.rs` 及 `src/view/` 下各子模块，以及 `docs/ui-design.md`。
- 不修改 `core/`，保持与主线 `bgm-tauri2@0f2cc01` 共享核心及 `prefs.json` v5 契约兼容。
