## ADDED Requirements

### Requirement: HTTP 契约

本机服务 MUST 遵循作者文档中的 16 个路由声明、17 个方法与路径组合、14 个通用动作、状态快照与错误码语义，并支持后续主线加入的字幕、分离、模型和任务接口。

#### Scenario: 通用动作和状态

- **WHEN** 外部脚本调用播放、查询、切歌、输出及扫描接口
- **THEN** 请求体、状态码和返回字段与上游契约兼容

#### Scenario: 节目单和输出冲突

- **WHEN** 节目有效时手动点播，或提交超过 8 路输出
- **THEN** 两类业务冲突均返回 409

### Requirement: 鉴权和 SSE

服务 SHALL 仅监听回环地址，按文档支持令牌、CORS、配置热更新与 SSE。

#### Scenario: 认证与来源

- **WHEN** 分别使用正确令牌、错误令牌和非本机默认来源请求
- **THEN** 正确令牌成功，错误令牌返回 401，未允许来源返回 403

#### Scenario: 事件订阅

- **WHEN** 通过 SSE 订阅后播放与切歌并修改令牌
- **THEN** 状态以约定格式更新，鉴权变化按契约生效

### Requirement: 后台任务

服务 MUST 为字幕生成、人声分离和 ASR 模型加载提供异步提交、详情和进度查询，并复用界面的模型与媒体处理流程。

#### Scenario: 提交与重复检测

- **WHEN** 客户端提交有效任务并在其完成前重复提交
- **THEN** 首次返回 202、任务快照及指向详情的 `Location`，重复提交返回 409

#### Scenario: 查询与进度

- **WHEN** 客户端按类型或状态筛选任务，或订阅某个任务进度
- **THEN** 列表返回符合条件的任务，单任务流从当前状态开始推送，并在发送终态后关闭

#### Scenario: 任务失败

- **WHEN** 正在执行的任务失败
- **THEN** 详情保留错误，事件流发送 `failed`，队列继续执行后续任务
