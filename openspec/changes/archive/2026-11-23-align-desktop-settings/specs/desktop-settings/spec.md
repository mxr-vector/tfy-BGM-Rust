## ADDED Requirements

### Requirement: 桌面设置行为

macOS 设置 SHALL 支持系统字体、登录启动、关闭行为、菜单栏和正在播放期间防休眠。

#### Scenario: 关闭行为和记住选择

- **WHEN** 选择记住关闭行为，重启后在设置恢复为每次询问
- **THEN** 重启后按已保存规则处理，取消记住后关闭会再次询问

#### Scenario: 后台与恢复

- **WHEN** 播放中最小化到菜单栏，随后从菜单栏还原
- **THEN** 音频继续播放，隐藏时释放屏幕防休眠锁，恢复可见时按开关重新取得

#### Scenario: 普通最小化与隐藏

- **WHEN** 正在播放且开启防休眠，窗口最小化、应用隐藏或播放暂停
- **THEN** 屏幕防休眠锁释放，恢复播放且窗口可见后重新取得

#### Scenario: 菜单栏不可用

- **WHEN** 启动时无法创建菜单栏项目，或选择关闭到菜单栏时项目创建失败
- **THEN** 窗口保持可访问，启动时将关闭到菜单栏的规则恢复为每次询问，操作失败时显示原因

#### Scenario: 登录启动保存失败

- **WHEN** 登录启动项无法写入，或系统操作成功后偏好无法保存
- **THEN** 界面保留上次保存的开关并显示错误，系统操作成功时尝试恢复原启动项

#### Scenario: 按字体族名或本地化名称查找

- **WHEN** 打开字体列表并搜索已安装的字体
- **THEN** 可用原始族名或本地化名称筛选，选择后以原始族名保存

### Requirement: 平台专属能力

设置 MUST 明确呈现 GPU 与 Windows、Linux 专属集成的适用范围。

#### Scenario: 平台条件

- **WHEN** 在 macOS 26+ 查看平台相关选项
- **THEN** 系统管理的 GPU 配置以及仅适用于其它平台的能力有准确的可用性说明
