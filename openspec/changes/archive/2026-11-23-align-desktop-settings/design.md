## Context

GPUI 已接入 macOS 字体、登录启动、菜单栏和防休眠。部署目标为 macOS 26+。

## Goals / Non-Goals

- 目标：完成 F13 系统设置与桌面集成的业务对齐和验收。
- 其他功能域通过各自的变更实施。

## Decisions

- 设置保留常规、播放、模型和第三方接入四页。GPUI 和 macOS 管理图形加速。Windows 媒体控件、空间音效与音频增强和 Linux MPRIS2 保留原始偏好字段，设置显示平台范围。
- AppKit 提供已安装字体及本地化标签，保存原始字体族名。中文覆盖优先，其次按中文标签和名称排序。字体清单在进程内缓存。
- 登录启动项继续使用 GPUI 自己的 LaunchAgent 标识。先写入或删除启动项，再保存偏好。保存失败时恢复原启动项。
- 菜单栏左键恢复窗口，右键提供显示和退出。关闭到菜单栏之前确认菜单栏项目可用。关闭菜单栏功能或启动时无法创建项目会把关闭行为恢复为询问。
- 播放、开关开启且主窗口可见时持有 IOKit 屏幕防休眠锁。隐藏、最小化、暂停或退出时释放，恢复可见且仍播放时重新申请。
