## Context

原生音频设备枚举和多路增益已接入，尚缺多设备实机端到端验证。

## Goals / Non-Goals

- 目标：完成 F07 多输出设备的业务对齐和验收。
- 其他功能域通过各自的变更实施。

## Decisions

走 CPAL 与 rodio 输出。各路独立增益乘以主音量，继续保留 default 作为第一路。

输出流按配置顺序排列，首个实际可用的输出提供进度。默认设备缺失时，其他已启用输出仍可播放。系统的默认设备 ID 变化、设备消失或流失效时刷新路由，从当前 PCM 和游标接入新增输出。断开的路由保持原有偏好；全部路由停用时保留可用的默认设备作静音时钟，已启用路由全部失效时停止并提示。各设备的输出流仍分别由硬件时钟驱动，长时间同步待双设备实测。
