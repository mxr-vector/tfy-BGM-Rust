## Context

GPUI 已接入监听、700 ms 防抖、后台扫描与 30 秒兜底。

## Goals / Non-Goals

- 目标：完成 F04 曲库实时监听的业务对齐和验收。
- 其他功能域通过各自的变更实施。

## Decisions

利用现有后台扫描和元数据缓存。防抖判定与消费在同一把锁内完成。后台快照校验代次、根目录、来源和扫描时间。当前根目录暂时不可读时，自动和手动刷新均保留已加载的数据。旧监听失联后，兜底扫描会在目录恢复时尝试订阅。

跨分类移动要求同一批次中只有一条匹配的移除和新增。同名存在多种配对时按增删上报。

## Risks / Trade-offs

实现对照 `e59ee18` 文档与 `bgm-tauri2@8ba4f85` 的监听代码。独立探针返回 `unable to start FSEvent stream`，真实批量刷新的时延待实机验收。
