- 格式检查、全目标编译与 OpenSpec 严格校验通过。编译使用 GPUI 运行时着色器功能。
- GPUI 测试通过 126 项。5 项本机 API 集成测试与 4 项 ASR 下载测试在绑定回环端口时得到权限错误。
