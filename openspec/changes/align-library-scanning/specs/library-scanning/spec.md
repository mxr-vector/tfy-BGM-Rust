## ADDED Requirements

### Requirement: 多格式递归扫描

曲库 MUST 递归扫描已注册分类，识别大小写不敏感的 FLAC、WAV、M4A、MP3、OGG，并按该顺序选择同主干的格式。

#### Scenario: 同名不同格式

- **WHEN** 同一分类发现 track.flac 和 track.mp3
- **THEN** 列表只显示 FLAC，稳定键为分类 ID 加文件主干，扫描结果包含去重告警

#### Scenario: 目录边界

- **WHEN** 曲库包含分类子目录、根目录单曲、未注册目录和回收站
- **THEN** 仅已注册分类中的合法曲目可见，根目录和未注册目录会报告警告

### Requirement: 分类与查找

GPUI SHALL 对齐分类新增和更新规则，并支持推荐顺序、中文曲名排序及文档定义的检索字段。

#### Scenario: 中文列表和检索

- **WHEN** 用户切换曲名排序并按斜杠聚焦已有查询
- **THEN** 列表按中文规则稳定排序，查询文本全选并可命中分类中英文名与英文标签

#### Scenario: 推荐顺序

- **WHEN** 用户在推荐排序下拖排行并重启
- **THEN** 当前会话保留拖排结果，重启重新采用扫描顺序
