# audio-diagnostics Specification

## Purpose

在播放工作区展示来源音频的波形、频谱、响度和异常，辅助检查素材和循环点。分析结果结合当前播放位置、A/B 循环范围以及源文件读取状态展示。

## Requirements

### Requirement: 源文件诊断

诊断 MUST 从未归一化的 PCM 得出 72 段频谱、K 加权响度、波形和整曲判定。

#### Scenario: 削波和相位

- **WHEN** 打开含削波、反相或长静音样本的诊断面板
- **THEN** 严重样本得到「建议处理」结论，显示相应指标及当前循环区间

#### Scenario: 导出目标变化

- **WHEN** 修改归一化预设后再次打开同一个已解码音轨
- **THEN** 源文件指标保持一致，目标响度只更新对照显示

#### Scenario: 播放实时诊断

- **WHEN** 源音频继续播放，或当前音轨切换、加载失败
- **THEN** 面板显示 72 段平滑频谱、最近 400 ms 源响度和最近 2048 帧单声道下混峰值；等待新音轨或播放源失效时隐藏旧音轨指标

### Requirement: 整曲诊断内存生命周期

诊断窗口 MUST 同一时间仅执行一次后台整曲分析。

#### Scenario: 诊断期间切歌

- **WHEN** 正在分析曲目时连续切歌
- **THEN** 当前曲目的实时指标继续更新，整曲分析空闲后处理当前曲目
- **AND** 旧曲目的报告不会显示为当前曲目的结果
